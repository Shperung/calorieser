# Ідеї на потім

Після кроку 14 плану в `AGENTS.md`. З аналізу MyFitnessPal / Yazio / Lose It! / Cal AI / MacroFactor / Cronometer / Noom; докладніше — `docs/research.md`.

Пріоритет — зверху. Перші 5 — найбільша користь при мінімумі нових бібліотек, працюють на iOS / Android / Web.

Не реалізовувати пункти з цього файлу без явного запиту.

1. Нещодавні / улюблені страви — повтор в один тап з `meals`, без AI.
2. Щоденник: правка збереженого прийому, зміна часу, перегляд минулих днів, групи «сніданок / обід / вечеря».
3. Тренд ваги (ковзне середнє) + прогноз дати досягнення `targetWeightKg` на тому ж графіку.
4. Push-нагадування (`expo-notifications`): щотижнева вага, прийоми їжі.
5. Вода: окрема колекція, кнопки «+250 мл».
6. Адаптивна норма (як MacroFactor): раз на 2–4 тижні порівнювати з'їдене з динамікою ваги і коригувати `dailyTarget`.
7. Тижневий звіт: середні ккал / БЖВ, дні в нормі, зміна ваги + порада від Gemini з урахуванням здоров'я.
8. Сканер штрихкодів: `expo-camera` + Open Food Facts (на web — ручний ввід коду).
9. Мікронутрієнти в AI-схемі: клітковина, цукор, натрій (важливо для діабету / гіпертонії); денні ліміти з `dailyTarget`.
10. AI-чат-нутриціолог з контекстом профілю, здоров'я і останніх прийомів (аналог `startCoinChat` з numismat).
11. Генерація меню / рецепту під залишок ккал / БЖВ на сьогодні і обмеження здоров'я.
12. Обхвати тіла і фото прогресу.
13. Інтервальне голодування: таймер вікна харчування (з перевіркою на протипоказання, напр. діабет / вагітність).
14. Кроки й активність: Apple Health / Health Connect (потрібен development build, не на web).
15. Серії днів, досягнення.
16. Зберігання фото їжі (GridFS / S3 / R2) для історії.
17. Офлайн-черга записів.
18. Перед публікацією в сторах: видалення акаунта з усіма даними, ручне додавання страви без AI (альтернатива при відмові від згоди), експорт CSV, вхід через Google / Apple (OAuth).
19. Темна тема, локалізація uk / en.
